⚙ 初回設定（YouTube APIキー）

このページ単体でYouTubeの全動画一覧を安定して取得するには、GoogleのYouTube Data APIキーが必要です。キーはこのページ内だけで使い、サーバーには送信しません。利用上限やキーの制限はGoogle Cloud側で設定してください。

Google Cloudでプロジェクトを作成し、「YouTube Data API v3」を有効化してAPIキーを発行してください。チャンネルIDは設定済みです。

公開されている動画を対象にします。非公開・削除済み動画は取得できません。APIキーと動画一覧はこのブラウザのローカル保存領域に保存され、次回は入力・取得を省略できる場合があります。共有端末では使わず、不要になったら「キーを消す」を押してください。
